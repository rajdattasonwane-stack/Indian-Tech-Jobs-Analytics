📊 Indian Tech Jobs Analytics Dashboard
🚀 Project Overview
The Indian Tech Jobs Analytics Dashboard is an interactive Power BI project designed to analyze trends in the Indian technology job market. The dashboard provides insights into job demand, salary distribution, skill requirements, company hiring patterns, and geographical trends.

This project demonstrates data cleaning, transformation, modeling, visualization, and business intelligence reporting using Power BI.

🎯 Objectives
Analyze hiring trends across the Indian tech industry
Identify the most in-demand skills
Understand salary distributions across roles
Explore company-wise and location-wise hiring patterns
Build an interactive dashboard for data-driven decision-making
